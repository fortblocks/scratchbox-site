How it works

Four rules. No cleaner app.

1. Inbox is a folder

~/Scratchbox/{Inbox, Kept, Expired} is Finder. Not a vault. Open it anytime.

2. Never silent delete

Pro expiry moves to Expired for a day, then system Trash. Undo resets the clock.

3. Downloads stay Downloads

Watch Downloads only moves new, finished files. No symlink. No replacing the folder.

4. Local only

No account. No upload. Quit restores the screenshot path when you ask it to.
