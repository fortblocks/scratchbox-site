Nothing stays unless you keep it.

Scratchbox is the default landing zone for screenshots and other throwaway files on Mac. A real Finder folder that empties itself.

Download for Mac Site source

Open the unsigned build

  1. Unzip Scratchbox-mac.zip and open Scratchbox.
  2. When macOS warns, click Done.
  3. Go to System Settings → Privacy & Security → Open Anyway.
  4. Look in the menu bar for the box. There is no Dock icon.

macOS 14 or later. Notarized disk image comes next.

What it does

  • Creates ~/Scratchbox/{Inbox, Kept, Expired}
  • Points Cmd-Shift-3 / 4 at Inbox instead of Desktop
  • Keep moves a file to Kept. Delete goes to Trash.
  • Paid trial: old Inbox files sit in Expired for 24 hours, then Trash
  • Local only. $12 one-time when payments ship. No subscription.
